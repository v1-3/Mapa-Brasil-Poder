# Mapa Brasil Poder

An interactive history of Brazil's party power index, 1947–2026.

**Public website:** https://v1-3.github.io/Mapa-Brasil-Poder/

## Website files

- `docs/index.html` — the complete website, including styles, data and JavaScript.
- `docs/.nojekyll` — serves the files directly through GitHub Pages.

GitHub Pages publishes the `docs` directory on the `main` branch. No build or package installation is required. The page uses Google Fonts and links to its historical sources.

To update the website, edit `docs/index.html` or replace it with the revised self-contained HTML, then commit and push to `main`. Check the Pages deployment and public URL after publishing.

The index uses estimates and modeling assumptions described on the page. Publication does not constitute independent verification of every historical value.

Older drafts remain recoverable from Git history. Local research, draft archives and review artifacts are excluded from the deployed website and future repository additions by `.gitignore`.
